这个项目是由24KRMB.COM官方制作的金融任务**技能 (Skills)** 目前还处于不断的更新和测试中；

**技能 (Skills)**是智能体能力的核心，可以理解为封装好的**专业领域知识和方法论**。它们告诉智能体在特定金融任务中应遵循的**步骤、逻辑和规范**。每当任务相关时，智能体便会自动激活它们。技能按**垂直业务领域**进行分类，以下是所有技能的全面讲解。

## 技能相关

### 1. 核心分析技能 (`financial-analysis`)
这是所有其他垂直的基础！提供了最通用的宏观分析，财务建模，以及图表制作能力。当前已实现的子技能：

#### 1-1 金融新闻技能 (`finnews`)

金融圈最好的新闻技能，通过 `browser_use` 工具实时抓取全球金融新闻。覆盖以下分类：

| 分类 | 说明 |
|------|------|
| **Central Banks** | 全球 20 家央行与金融机构官方站点 |
| **Exchanges** | 全球 22 家交易所官方站点 |
| **Finance** | 国内主流财经媒体 + 官方机构（统计局、发改委、证监会、央行） |
| **Futures** | 国际财经媒体（Bloomberg、WSJ、FT、Reuters、CNBC 等）+ 东方财富期货资讯 |
| **Politics / Society / World / Tech / Sports / Entertainment** | 综合新闻聚合 |

#### 1-2期货分析师收评 (`futures-analyst`)

生成专业的期货市场分析报告，覆盖国内商品期货全品种，输出精美可交互的 HTML 报告。

**报告版本**：盘中版 / 收盘版 / 夜盘前瞻版 / 周末版
**板块覆盖**：黑色系、有色金属、能源金属、能源化工、油脂油料、农产品、谷物、软商、贵金属、航运、煤炭（共 11 个板块，70+ 品种）

### 2. 投资银行技能 (`investment-banking`)

专为交易执行和承揽材料设计。

### 3. 证券研究技能 (`equity-research`)

覆盖从信息追踪到报告发布的完整研究流程。

### 4. 私募股权技能 (`private-equity`)

从项目搜寻、尽职调查到投后管理的全链条。

### 5. 财富管理技能 (`wealth-management`)

面向客户顾问，提升客户服务和报告效率。

### 总结

这些技能将金融领域的隐性知识**结构化为可复用的方法论**。它们共同的特点是**高度可定制**——你可以直接修改对应的Markdown文件，来调整分析方法、术语或输出格式，使其完全契合你所在机构的标准工作流程。
