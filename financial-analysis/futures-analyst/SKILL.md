# 期货分析师收评技能

本技能用于生成专业的期货市场分析报告，覆盖国内商品期货全品种，输出为精美可交互的 HTML 报告文件。

## 触发条件

当用户请求以下任一场景时，立即激活本技能：

- 定时任务
- Invoke when user asks for futures analysis, market review, or commodity report.
- 提及"futures-analyst"关键词

## 执行流程

### 第一步：确定报告版本

根据`cron`获取当前时间，自动判断报告版本：

- **盘中版**：交易日上午 9:00 - 下午 15:00
- **收盘版**：交易日下午 15:00 - 晚上 19:00
- **夜盘前瞻版**：交易日晚上 19:00 - 次日凌晨 20:50
- **周末版**：周六为当周总结版 - 周日为下周展望版，行情数据用最新的数据，财经日历用当日的数据

### 第二步：采集期货行情数据

#### 获取数据

#### 根据获取的行情数据计算

- 金银比：COMEX黄金与COMEX白银的比值
- 金油比：COMEX黄金与NYMEX原油的比值
- 螺矿比：螺纹钢与铁矿石的比值
- 螺卷差：螺纹钢与热卷的差值
- 猪粮比：生猪与玉米的比值

### 第三步：采集各板块资讯与产业链分析

对以下每个板块，执行**一轮深度搜索**：

1. **优先使用 `tavily_research`**：当 API 配额充足时，使用深度研究模式
2. **降级使用 `tavily_search`**：当 `tavily_research` 达到使用限制时，自动降级为单次搜索模式（`max_results=3`）

搜索关键词格式：`"{板块名} 期货 新闻 持仓 产业链"`，同时提取重要资讯、机构持仓变化、产业链逻辑链。

### 第四步：数据校验

对采集到的数据执行以下校验：

- **时间戳校验**：检查数据时间戳，排除过期数据（非当日数据）
- **异常值检测**：涨跌幅超过 ±5% 的品种需标注"⚠️ 异常波动"，并在报告中特别提示

### 第五步：识别日内明星品种

从行情数据中筛选：

- 涨幅最大的品种
- 跌幅最大的品种
- 日增仓最大的品种
- 投机度最高的品种

对每个明星品种进行深度解读，包括：行情异动原因、资金面分析、产业链驱动因素、技术形态分析、后市展望。

### 第六步：生成 HTML 报告

运行 `scripts/report_generator.py` 脚本，读取 `assets/report_template.html` 模板，填充采集的行情数据和分析内容，生成最终 HTML 报告。

**执行命令**：

```bash
python scripts/report_generator.py --quotes scripts/quotes_YYYYMMDD_HHMMSS.json --analysis analysis.json --calendar calendar.json --version "收盘版"
```

**参数说明**：

- `--quotes`：行情数据 JSON（必须，由 fetch_quotes.py 生成）
- `--analysis`：分析数据 JSON（可选，由 AI Agent 通过 tavily_search 采集后整理）
- `--calendar`：财经日历 JSON（可选）
- `--version`：报告版本（盘中版/收盘版/夜盘前瞻版/周末版）

**生成逻辑**：模板中的 `{{占位符}}` 会被 report_generator.py 替换为实际数据，确保最终 HTML 与模板结构完全一致。

**文件命名规则**：

- 盘中版：`YYYYMMDD_期货盘中版.html`
- 收盘版：`YYYYMMDD_期货收盘版.html`
- 夜盘前瞻版：`YYYYMMDD_期货夜盘版.html`
- 周末版：`YYYYMMDD_期货周末版.html`

**输出路径**：用户桌面（macOS: `~/Desktop/`，Windows: `%USERPROFILE%\Desktop\`，Linux: `~/Desktop/`）

## HTML 报告结构

报告必须包含以下完整结构：

### 1. 封面信息

- 报告标题：期货市场收评分析报告
- 报告日期：YYYY年MM月DD日
- 版本标识：盘中版 / 收盘版 / 夜盘前瞻版
- 生成时间戳

### 2. 市场情绪

- 当日市场整体情绪概述（偏多/偏空/震荡/分化）
- 宏观指标卡片：美元指数、USDCNH、NYMEX原油、COMEX黄金、COMEX白银、A50期指当月连续、沪深300、道琼斯DJIA
- 每个指标显示：最新值、涨跌幅、对国内商品期货的影响方向

### 3. 重要比值分析

- 根据获取的行情数据显示：金银比，金油比，螺矿比，螺卷差，猪粮比

### 4. 各板块分析（11个板块逐一分析）

每个板块包含以下子模块：

#### 4.1 行情总览

- 板块内品种行情表格（品种、最新价、涨跌幅、成交量、持仓量、日增仓、投机度、成交额、震幅）
- 涨跌统计：上涨品种数 / 下跌品种数 / 持平品种数
- 板块整体情绪判断

#### 4.2 产业链分析

- 上游原料端：供应情况、价格变化、对中游成本影响
- 中游生产端：产能利用率、开工率、库存变化、利润情况
- 下游需求端：订单情况、消费数据、终端市场表现
- 逻辑链传导：上游→中游→下游的驱动关系与传导路径

#### 4.3 重要资讯影响

- 当日产业链重大消息列表（每条包含：资讯标题、来源、影响方向、影响解读）

#### 4.4 机构持仓追踪

- 主要席位持仓变化表格（席位名称、多单变化、空单变化、净持仓变化）
- 机构观点汇总（多头观点、空头观点、中性观点）

#### 4.5 技术形态

- 关键支撑位与压力位
- 趋势判断（多头/空头/震荡）
- 关键技术信号

#### 4.6 后市展望

- 短期走势预判（1-3个交易日）
- 核心驱动因素
- 风险提示

### 5. 日内明星品种

- 涨幅榜 Top 3 深度解读
- 跌幅榜 Top 3 深度解读
- 日增仓榜 Top 3 深度解读
- 投机度榜 Top 3 深度解读
- 每个品种包含：行情概览、异动原因、资金面分析、产业链驱动、技术形态、后市展望

### 6. 财经日历

- 当日全球经济数据发布
- 相关事件解读

## 输出要求

1. 报告由 `scripts/report_generator.py` 基于 `assets/report_template.html` 模板生成，视觉风格与交互功能已内置于模板中
2. 报告数据必须真实反映采集到的行情和资讯
3. 分析内容必须基于数据，逻辑清晰，有理有据
4. 对无法获取的数据，明确标注"数据暂缺"，不得编造
5. 报告末尾添加免责声明：本报告由AI智能体生成，仅供参考，不构成投资建议
